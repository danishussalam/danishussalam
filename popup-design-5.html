Design 5: Expandable Card Overlay

Large card that slides up from bottom with bold header and CTA buttons

Framework Guide

APE

Action, Purpose, Expectation

What It Does

APE emphasizes actionable outcomes. Specify what action you want, why it matters (purpose), and what success looks like. This framework is ideal for structured, measurable tasks.

Key Components

Action

What needs to be done

Purpose

Why it matters

Expectation

Success criteria

Best For

Project work, process optimization, and deliverable-focused tasks. Use when you need clear, measurable results.

Example Prompt

"As a product manager, I need to write a feature proposal (action) that justifies why this feature improves user retention (purpose), formatted as a 2-page document with cost-benefit analysis (expectation)."
