APE

Action, Purpose, Expectation

What It Does

APE emphasizes actionable outcomes. Specify what action you want, why it matters (purpose), and what success looks like.

Best For

Project work, process optimization, and deliverable-focused tasks.

Goal-Oriented Tasks with clear deliverables

Perfect For

Use APE when you need clear, measurable results. Perfect for:

  • Business tasks and proposals
  • Development sprints
  • Process improvement
  • Any project with quantifiable outcomes

Avoid When

APE is less ideal for creative, open-ended tasks that don't have clear success metrics.

Example Prompt

"As a product manager, I need to write a feature proposal (action) that justifies why this feature improves user retention (purpose), formatted as a 2-page document with cost-benefit analysis (expectation)."

What Makes It Work

This prompt clearly defines:

  • Action: Write a feature proposal
  • Purpose: Justify retention improvement
  • Expectation: 2-page document with analysis
